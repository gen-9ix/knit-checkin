# 一天一針

一個手作感的每日打卡頁：每天按一下，就在牛皮紙板上釘一根透明圖釘，紅色毛線會繞過去垂下來，連起每一天。

- 釘好後可以貼一張心情便利貼：選顏色、選一個顏文字、寫二十字以內的小記
- 用手指可以拉扯掛著的毛線
- 四首即時生成的背景音樂：午後鋼琴、音樂盒、雨天窗邊、散步

紀錄只存在打開它的那台裝置的瀏覽器裡（localStorage），不會上傳。

## 加到手機主畫面

用 GitHub Pages 打開後：

- iPhone：Safari → 分享 → 加入主畫面
- Android：Chrome → ⋮ → 加到主畫面

## 檔案

- `index.html`：整個頁面（樣式、程式都在裡面）
- `manifest.webmanifest`、`icon-*.png`：主畫面用的名稱與圖示
